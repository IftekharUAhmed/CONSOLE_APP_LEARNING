## 🧭 Amader Golden Rule: **What → Why → How**

Je kono jinish shikhle 3 ta proshner uttor amader jana lagbe:

1. **What** — Jinish ta ki? (definition, sohoj bhashay)
2. **Why** — Keno lage? Eta na thakle ki shomossha hoto?
3. **How** — Kivabe likhte hoy? (code + line by line explanation)

Er sathe thakbe:
- ⚠️ **Common Mistakes** — beginner ra kothay bhul kore
- 🏋️ **Exercise** — tumi nije likhbe (copy-paste na!)
- 🎤 **Interview Questions** — interview te ki jiggesh korte pare

## 🛒 Amader Project: `ShopConsole`

Alada alada choto program na baniye, amra **ekta e app** dhire dhire boro korbo —
ekta mini shop:

```
Phase 1-3   →  Product er dam, quantity, total hishab (basic syntax)
Phase 5     →  Onek product er list (collections)
Phase 7-9   →  Product, Cart, Order class (OOP)
Phase 12    →  Data file e save (JSON)
Phase 14-16 →  SOLID, Factory, Repository, DTO, Service, Controller, DI
Phase 18    →  Same logic ASP.NET Core Web API te niye jawa (e-commerce er bridge)
```

Ete kore protiti notun concept "keno lage" sheta nijer chokhe dekhbe — karon
ager code e shomossha dekha dibe, ar notun concept seta solve korbe.
